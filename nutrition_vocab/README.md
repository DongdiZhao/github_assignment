# 营养学单词（Nutrition Vocab）

面向 **RD 注册营养师考试**、从零开始学营养学的人的专业英语词汇 App（网页应用 / PWA）。可以添加到手机主屏幕，离线也能用。

## 词库
共 **1149 个词**，按 RD 考试范围分成 8 个板块、86 个主题。同一类的词放在同一个主题里一起记，比如 `-ose` 糖类、`-ase` 酶类、`-ic acid` 酸类、`-emia` 血症、`-itis` 炎症。每个主题都附有词根和记忆提示。

每个词都有：美式音标、中文释义、英文例句和例句翻译。

## 功能
- **学习**：单词卡和词表。单词卡上显示同组的词和记忆提示。智能排序依次安排：待复习的词、新词（同组连在一起）、不熟的词。
- **🎵 播放列表**：把选中的单词拼成一整段 MP3。锁屏或切到后台也能继续听，可以从锁屏切换上 / 下一个词，也可以保存到手机离线听。有讲解、英→中自测、中→英自测、快速过词四种模式。
- **🗣️ 语音问答**：纯听、跟读、英译中、中译英四种模式，支持语音指令（重复 / 下一个 / 不知道 / 暂停 / 停止）。
- **📝 测试**：五种题型随机混合，每次重新抽题。答错过、不熟的词更容易被抽到。干扰选项优先从同组的相近词里选，用来练习辨析。
- **📊 记录**：掌握进度、错题本、连续学习天数和历史成绩，支持导出 / 导入备份。

## 录音
`audio/` 目录下是用开源神经网络语音合成模型 Kokoro 离线预先生成的录音：英文用美式女声 `af_heart`，中文用 `zf_001`。每个词有 4 段：单词、释义、例句、例句翻译。

所有录音都是 24 kHz 单声道 32 kbps CBR MP3，每帧固定 96 字节（24 毫秒），文件里没有 ID3 / Xing 头，因此 App 可以直接把多个文件按字节拼成一个完整的播放列表。录音加载失败时，App 会自动改用手机自带的语音。

## 修改词库
词库在 `vocab/*.js`，每个词的格式是 `[英文, 音标, 中文, 例句, 例句翻译]`，每个分组可以写一条 `tip` 记忆提示。新增或修改词以后，需要重新生成这些词的录音。
