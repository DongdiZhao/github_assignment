# 营养学单词（Nutrition Vocab）

面向营养学零基础学习者的专业英语词汇 App（网页应用 / PWA），可添加到手机主屏幕离线使用。

- **词库**：349 个词，分为 人体生化营养学 / 解剖学 / 食物营养学 / 运动营养学 四大板块、19 个主题；每个词含音标、中文释义、例句及翻译。
- **学习**：单词卡（智能排序：到期复习 → 新词 → 不熟的词）+ 可搜索词表。
- **语音**：纯听、跟读、英译中问答、中译英问答四种模式；支持语音指令（重复 / 下一个 / 不知道 / 暂停 / 停止）。
- **测试**：五种题型随机混合，每次重新抽题、打乱选项，错得多、不熟的词更容易被抽到。
- **记录**：掌握进度、错题本、连续学习天数、历史成绩，支持导出 / 导入备份。

所有数据只保存在本机浏览器中。词库位于 `words.js`，格式为 `[英文, 音标, 中文, 例句, 例句翻译]`，可直接增改。
